QauypZhoq + PhishTank

1. Put index.html, update_phishtank.py and this .github folder in the root of your GitHub repository.
2. In GitHub, open Settings -> Secrets and variables -> Actions -> New repository secret.
   Name: PHISHTANK_APP_KEY
   Value: your PhishTank application key (optional, but recommended).
3. Make sure GitHub Actions is enabled and the workflow has permission to write to the repository.
4. In Render, enable Auto-Deploy from the connected GitHub repository.
5. Run the workflow once manually: GitHub -> Actions -> Update PhishTank database -> Run workflow.
   The workflow will then refresh the database every 6 hours and commit phishtank.txt.

Manual update:
  python update_phishtank.py
or
  python update_phishtank.py YOUR_APP_KEY

Important:
- phishtank.txt is generated by the updater and must be in the same published directory as index.html.
- The existing index.html already fetches phishtank.txt on page load, imports its URLs into the checker,
  and checks submitted links against the imported PhishTank entries.
- A missing match is not proof that a website is safe.
- The scheduled workflow requires repository write access and Render auto-deploy to be enabled.
